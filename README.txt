Aastha Birthday Website
========================
Open index.html in a modern browser.

Included:
- Lavender / ivory / blush / muted rose / subtle gold palette
- Animated rose-petal opening atmosphere
- Lightweight procedural 3D avatar using Three.js CDN
- AI/ML + C++ terminal aesthetic
- Old-scroll love letter in English + Hinglish
- Separate randomly shuffled memory room using all 21 supplied images

Music:
The site is wired for assets/bairan.mp3, but the song audio file was not supplied.
For a local/static copy, add a legally obtained copy named:
assets/bairan.mp3

The website uses Three.js and Google Fonts via CDN, so the 3D avatar/fonts need internet access unless you later vendor those dependencies locally.
